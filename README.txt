DESCRIPCIÓN:
Aplicación web que consume la API REST de MockAPI para realizar operaciones CRUD sobre estudiantes y cursos. Incluye búsqueda, validaciones, relación estudiante-curso, protección contra eliminación de cursos asociados y reporte de cantidad de estudiantes y edad promedio por curso.

TECNOLOGÍAS:
HTML5, CSS3, JavaScript nativo, Fetch API, async/await, Bootstrap 5, SweetAlert2 y MockAPI.

DISTRIBUCIÓN:
- Integrante 1: estudiantes.js (CRUD de estudiantes, búsqueda, formulario y relación con cursos).
- Integrante 2: cursos.js (CRUD de cursos, búsqueda, validaciones e integridad).
